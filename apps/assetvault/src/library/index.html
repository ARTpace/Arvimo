    使用说明与反馈

    三步上手：搜索框里输关键词或粘贴链接 → 卡片上加入模型库 / 下载 → 已下载的资产一键送进 Blender，或用输出的文件夹直接拖进 Unity。

    01搜索与筛选一个搜索框服务所有平台
    • 选平台：搜索框左侧切换；「全部平台」同时检索 Sketchfab、ArtStation 与 Poly Haven，结果交错排列，状态行逐源报进度。
    • 模型模式 / 图片模式：侧栏顶部的两个快捷键。模型模式只收能转 3D 的资产，并把两平台的筛选合并成一棵统一分类树；图片模式只看 ArtStation 作品、按原图比例排成瀑布流。再点一次当前模式即退出。
    • 筛选树：分类按主题分组，组默认折着、点组头展开；排序与范围平时只显示当前值，点开即改。分类、可下载、动画、精选都会真的发给平台接口，不是只在当前结果里过滤。
    • 检索词组：点一下搜索框弹出，按「最近检索 / 链接解析 / 今日主题 / 相近词」分组；方向键选、回车即检索或回放，右上角可清除记录。记录只保存在这台电脑的浏览器里。
    • 粘贴链接：作品页 / 作者页 / 合集页地址直接粘进搜索框，平台按域名自动判定；解析结果单独占用结果区，点「返回搜索结果」交还。
    • 中文按原文搜索，不做静默翻译。
    02收藏与模型库在线结果不自动入库
    • 点「加入模型库」或爱心收藏后才保留；单纯下载只留在下载记录中。
    • 旧版本的模型列表、收藏和记录会原样保留，不会被删除。
    03下载与导出后台队列 · 文件夹输出 · GLB + FBX
    • 点卡片「下载」即入队，不弹确认框；进度、批量取消 / 重试、打开所在文件夹都在「下载管理」。
    • 关掉网页任务照跑；服务关闭或电脑关机会中断任务，重启后从头重试（不是断点续传）。
    • 默认输出文件夹（可直接拖进 Unity）并同时保存 GLB + FBX，FBX 需要本机 Blender；ZIP、贴图压缩、下载内容在「设置」里改。
    • 任务过 ZIP / 目录校验后才标完成，并记录 SHA-256；同名不覆盖。遇到权限、站点限制或模型不兼容，任务会保留真实错误，不会假装下载完成。
    • Sketchfab 模型由后台 Chrome / Edge 转换；ArtStation 用 mviewer 转内嵌场景，不需要浏览器。两者共用同一条队列与同一套校验。
    043D 预览左键旋转 · 右键缩放 · 中键平移 · 双击重置 · Shift+左键转灯光
    • Sketchfab 用官方嵌入播放器，ArtStation 读作品内嵌的 Marmoset 场景，Poly Haven 在本地渲染官方 1K glTF。
    • HDRI 与贴图是全景图 / 平铺图，转不了视角，按钮会直接带你去官网。
    • 没有内嵌场景的纯图片作品不弹空预览窗，直接打开官方作品页。
    05边界与许可说清楚做不到什么
    • 在线搜索只展示接口可访问的公开模型，不含 Fab 商城；不保证与官网数量、排序一致。
    • 普通网页解析不执行 JavaScript，识别不到登录内容或动态加载的全部链接。
    • 公开展示不等于获得使用授权，请遵循模型许可证；署名信息会写进输出包的 info.json。
    • 本地模型库与收藏保存在这台电脑的浏览器里，不是云端备份。
    • 独立工作台不做浏览器扩展式贴图捕获；出现贴图提示请检查导出外观与包内 MISSING_BLIT.txt，骨骼、动画与材质兼容性取决于原引擎。

    资产标签

    平台标签只读；星光图标表示 AI 补充的；还可以加「我的标签」、评分和备注，全部自动保存到本机。

    标签管理

    管理「我的标签」：重命名、合并到其他标签、或从所有资产上删除。AI 标签可随时重新生成，不在这里管。
    导入本地文件夹

    把已有的素材目录加进资产库：目录里的文件夹 / 带 info.json 的资产包会自动出现在库里。只登记路径，不复制、不改动磁盘上的文件。
    此电脑的资产保存位置

    保存位置只影响当前电脑，不会修改主机目录。完成的资产将自动保存为 ZIP。

    如果没有显示文件夹选择按钮，当前浏览器或 HTTP 连接不支持网页直接指定目录，请按以下步骤设置：

    1. 打开浏览器的“设置 → 下载”。
    2. 将“位置”更改为自己的资产文件夹。
    3. 关闭“下载前询问每个文件的保存位置”，允许本网站自动下载多个文件。

    之后本网站的资产会自动保存到该目录。此设置也会影响浏览器的其他下载；网页无法读取浏览器设置中的完整本地路径。若要只为本站授权文件夹，需要浏览器支持并通过受信任的 HTTPS 访问。
