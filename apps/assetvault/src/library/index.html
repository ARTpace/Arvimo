      使用说明与反馈
      1. 1搜索输关键词，或把作品 / 作者 / 合集链接粘进搜索框
      2. 2入库卡片上点「加入模型库」或「下载」
      3. 3用起来一键送进 Blender，或把输出的文件夹直接拖进 Unity
      01搜索与筛选一个搜索框管三个平台
      • 选平台搜索框左侧切换；「全部平台」同时检索 Sketchfab、ArtStation 与 Poly Haven。
      • 模型 / 图片模式侧栏顶部两个快捷键：模型模式只收可转 3D 的资产、两平台筛选合成一棵树；图片模式只看 ArtStation、按原图比例瀑布流。再点一次当前模式即退出。
      • 筛选树分类按主题分组、默认折起；排序与范围点开即改。分类、可下载、动画、精选都会真实下发给平台接口，不是只在本地结果里过滤。
      • 检索词组点搜索框弹出，分最近检索 / 链接解析 / 今日主题 / 相近词；方向键选、回车检索，记录只存在本机。
      • 粘贴链接作品 / 作者 / 合集地址直接粘进搜索框，按域名判定平台；解析结果独占结果区，可一键返回。
      • 中文按原文搜索，不做静默翻译。
      02收藏与模型库在线结果不自动入库
      • 入库时机点「加入模型库」或爱心收藏才保留，单纯下载只进下载记录。
      • 旧数据早版本的模型列表、收藏与记录原样保留，不会删。
      03下载与导出后台队列 · 文件夹输出
      • 入队点卡片「下载」即开始，不弹确认框；进度、批量取消 / 重试、打开所在文件夹都在「下载管理」。
      • 中断关掉网页任务照跑；服务关闭或电脑关机则从头重试，不是断点续传。
      • 产物默认输出文件夹（可直接拖进 Unity），同时存 GLB + FBX，FBX 需本机 Blender；ZIP、贴图压缩、下载内容在「设置」里改。
      • 校验过 ZIP / 目录校验才标完成并记录 SHA-256，同名不覆盖；出错保留真实错误，不假装下载完成。
      • 转换Sketchfab 走后台 Chrome / Edge，ArtStation 用 mviewer 转内嵌场景，共用同一条队列与同一套校验。
      043D 预览左键旋转 · 右键缩放 · 中键平移
      • 操作左键旋转、右键缩放、中键平移、双击重置、Shift + 左键转灯光。
      • 来源Sketchfab 用官方嵌入播放器，ArtStation 读作品内嵌 Marmoset 场景，Poly Haven 本地渲染官方 1K glTF。
      • 不可转视角HDRI 与贴图是全景图 / 平铺图，按钮直接带你去官网。
      • 纯图片作品没有内嵌场景的不弹空窗，直接打开官方作品页。
      05边界与许可说清楚做不到什么
      • 范围只展示接口可访问的公开模型，不含 Fab 商城；数量与排序不保证与官网一致。
      • 解析普通网页不执行 JavaScript，登录内容与动态加载的链接可能识别不到。
      • 许可公开展示不等于获得授权，请遵循模型许可证；署名写进输出包的 info.json。
      • 存储模型库与收藏存在这台电脑的浏览器里，不是云端备份。
      • 贴图不做浏览器扩展式捕获；提示贴图缺失时看导出外观与包内 MISSING_BLIT.txt，骨骼 / 动画 / 材质兼容性取决于原引擎。

        资产标签

        平台标签只读；星光图标表示 AI 补充的；还可以加「我的标签」、评分和备注，全部自动保存到本机。

        标签管理

        管理「我的标签」：重命名、合并到其他标签、或从所有资产上删除。AI 标签可随时重新生成，不在这里管。
        导入本地文件夹

        把已有的素材目录加进资产库：目录里的文件夹 / 带 info.json 的资产包会自动出现在库里。只登记路径，不复制、不改动磁盘上的文件。
        此电脑的资产保存位置

        保存位置只影响当前电脑，不会修改主机目录。完成的资产将自动保存为 ZIP。

        如果没有显示文件夹选择按钮，当前浏览器或 HTTP 连接不支持网页直接指定目录，请按以下步骤设置：

        1. 打开浏览器的“设置 → 下载”。
        2. 将“位置”更改为自己的资产文件夹。
        3. 关闭“下载前询问每个文件的保存位置”，允许本网站自动下载多个文件。

        之后本网站的资产会自动保存到该目录。此设置也会影响浏览器的其他下载；网页无法读取浏览器设置中的完整本地路径。若要只为本站授权文件夹，需要浏览器支持并通过受信任的 HTTPS 访问。
