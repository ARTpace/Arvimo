# 右键菜单规范

共用入口：`createContextMenu`；统一名称与排序：`src/library/menu-policy.js`。
卡片、画板和空白区域提供各自可用的动作，由共享入口整理展示，不复制执行逻辑。

- 顺序：常用 → 整理 → 来源 → 新建 → 显示模式 → 显示内容 → 删除；空组不显示。
- 常用顺序：预览或打开 → 下载或保存 → 文件夹 → 收藏 → 入库或加入画板 → 发送。
- 名称简短，选择或输入后才执行的操作使用省略号；具体影响放悬停说明与删除确认中。
- 图标独立固定列宽，文字左对齐，所有项目保持相同行高。
- 主要操作直接点击执行，不增加“更多”子菜单。
- 删除、解散、移出不是同一行为，不能互换名称或执行逻辑。
- 卡片菜单操作卡片；空白菜单负责导入、新建、显示；已下载不重复提供下载。
- 新增动作先检查统一词表，复用已有名称、位置和回调；新能力须补齐适用状态测试。
