# 资源占用优化（2026-10-31）

- 内置 3D 预览改为按需绘制：OrbitControls change 事件续接阻尼帧，稳定后停止。灯光拖动、尺寸变化和页面重新可见会请求重绘；材质、通道等原有主动渲染入口保留。
- 关闭预览后立即停止绘制、释放模型资源；60 秒未重开则清空内存预览缓存和 Polyfork 几何缓存，将画布缓冲缩至 1×1。保留 WebGL 上下文规避既有二次打开黑屏问题。重开取消回收定时器，尺寸变化观察器在关闭期间不重新分配缓冲。
- 普通网格的固定正方形封面使用 content-visibility:auto 跳过屏幕外内容绘制，不改变卡片 DOM、选择状态和搜索行为。瀑布流及紧凑模式排除；这不是完整虚拟列表，不会回收全部离屏图片内存。

验证：29 项直接相关测试最终全部通过（其中一项旧的持续循环源码断言适配按需渲染后单独复测通过）；生产资源构建通过。真实页面 48 张卡片封面宽高一致，FreeStylized 材质预览首帧、旋转、滚轮缩放、关闭再打开正常，未捕获控制台错误。截图：artifacts/resource-optimization/preview-reopened.png。

限制：60 秒回收及恢复尺寸用模拟定时/渲染对象验证，未实际等待回收后重开。未手动覆盖所有平台、SBSAR 参数、通道和灯光手势，相关既有路径静态测试通过。未做进程隔离的前后 CPU、内存、显存对比，不承诺降幅。平台 iframe 预览器不受内置渲染调度控制。
