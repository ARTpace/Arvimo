# 顶部搜索岛

## 2026-11-20 收起态精修

- 收起态不显示平台名或“搜索”标签：平台入口使用图标，中间同步小猫当前气泡提示；无提示时显示“想找什么素材？告诉我吧”。展开后恢复平台名称与完整输入框。
- 收起态顺序：分类、平台、搜索摘要、模式切换与原有AI入口。分类一次点击打开抽屉，平台一次点击打开候选，均不展开搜索栏；摘要一次点击展开并聚焦输入。
- 鼠标靠近时轻微舒展岛体、提亮边框与眼睛；退出平滑恢复。系统减少动态效果时停用这些变化。键盘聚焦分类／平台不会触发整岛展开。
- 8项组件测试通过；本地真实界面确认分类抽屉和平台候选可直接打开，搜索岛保持收起。

## 目标与范围

将现有搜索面板增加为可选的顶部胶囊形态，减少常驻高度，让素材成为内容区主角。正常模式仍为首次使用默认值；用户可直接切换，偏好保存在当前浏览器／桌面 WebView 的 localStorage，不随账户同步。

借鉴 Daozai 的胶囊形态和状态反馈，不引入其 Rust、桌面置顶窗口或第三方源码。搜索仍在 Arvimo 窗口内，使用现有主题颜色，无新增依赖。

## 操作路径

| 操作 | 路径 |
| --- | --- |
| 进入灵动岛 | 正常面板右下方「灵动岛」，1 次点击 |
| 恢复正常模式 | 岛右端 ↗，1 次点击 |
| 输入搜索 | 直接点击岛内输入框，Enter 或搜索图标提交 |
| 类型切换 | 岛下方原有六种类型图标，1 次点击 |
| 筛选 | 岛内筛选图标，1 次点击打开原有抽屉 |
| 历史建议 | 聚焦输入框显示原有历史浮层，点击条目采用原逻辑 |
| 清空 | 输入框原有清空按钮，1 次点击 |

不通过「更多」或设置页切换模式。鼠标移出不收起正在编辑的内容；点击外部或 Esc 离开输入。键盘触发模式切换时保留焦点。切换形态不重新提交搜索、不改草稿、筛选、搜索结果或类型。

## 布局与状态

- 正常模式：保留原面板、小助手及原有功能，在面板右下方增加模式按钮，不挤压原有表单。
- 常驻岛：宽度上限 440px，高 48px，在内容区顶部居中贴边，上方无空隙，仅下方圆角；滚动复用原 sticky 吸顶。原类型栏排在下方。
- 桌面窗口：岛展开时给右上角窗口按钮留出空间；透明拖动层按岛的实际宽度让出命中区域，两侧空白继续拖动窗口。当前 debug 桌面版刷新页面即可重新读取标题层脚本；正式发布版需重新编译安装包。
- 输入：聚焦后平滑展开至最多 720px，受内容区宽度限制。直接使用原输入框、搜索与清空按钮。
- 搜索：小眼睛呼吸，显示搜索中／完成／失败状态。状态浮层和图搜缩略图放在类型栏下方，不推动素材列表。
- 历史：原浮层在岛模式下避开类型栏；原 ResizeObserver 跟随输入框宽度更新锚点。
- 窄屏：隐藏装饰眼睛，保留实际操作。浅色跟随现有主题变量；减少动态效果设置下关闭新增动画。
- 原有面板隐藏规则继续生效：画布、下载管理等页面不额外显示搜索岛。

## 实现位置

- `src/library/search-island.js`：移动原面板到占位容器，添加模式按钮、装饰眼睛和状态提示；监听原 `search-motion-state` 事件。
- `src/library/search-island.css`：隔离在 `[data-search-layout=island]` 下的布局覆盖；固定占位、绝对定位展开，避免内容跳动。
- `src/library/app.js`：初始化；路由更新搜索按钮时保留文字样式钩子和可访问名称。
- `src/library/search-history.js`：岛模式历史浮层锚点避开类型栏。
- `scripts/build-library.mjs`：将岛样式追加到最终样式，沿用原桌面资源同步链路。
- `test/library-search-island.test.js`：验证模式持久化、原节点和事件保留、状态反馈、存储异常降级。

## 验收

1. 正常与岛模式都能一次点击切换，刷新后恢复偏好。
2. 输入、清空、历史、类型、筛选、图搜及本地／在线搜索继续走原逻辑。

## 动效打磨（2026-11-20）

参考 [Daozai 的弹簧实现](https://github.com/Renly1994/xiaotang-daozai/blob/main/src/anim.rs) 中“打断后从当前状态继续”的原则、[Vaul](https://github.com/emilkowalski/vaul/blob/main/src/style.css) 的减速曲线，以及 [Sonner](https://github.com/emilkowalski/sonner/blob/main/src/styles.css) 的短时交互反馈。不引入这些项目的运行时依赖。

- 输入展开 420ms、收起 280ms，统一使用 `cubic-bezier(.32,.72,0,1)`，尺寸不做过冲。
- 正常／岛模式切换用浏览器 Web Animations API 的 FLIP 过渡，面板、类型栏和素材区从当前可见位置移向新位置。收为岛 320ms，恢复完整面板 400ms；业务状态即时生效，不等待动画。
- 新操作先读取当前画面几何位置，再取消旧过渡，避免快速反向时跳回起点；结束、取消、页面隐藏及系统启用减少动态效果时清理动画状态。
- 历史浮层按固定占位容器的中心定位，避免跟着输入区域的左边缘左右漂移；出现使用 200ms 的轻微位移与淡入。按钮使用 160ms 悬停／按压反馈。
- 桌面拖动层在模式变形期间跟随岛体实际位置，动画结束后停止逐帧跟踪。

验证：模式和原生拖动区域共 8 项针对性测试通过；浏览器查看了切换序列、输入展开、历史浮层、恢复正常与再次收起。快速打断、减少动态效果及动画清理由单元测试覆盖；未测量帧率，未在原生桌面窗口实测拖动层的动态命中。证据在 `.oil-ui/search-island/motion-*.jpg`。

### 样式切换转场修正

原 FLIP 方案先更改布局再变换当前元素，文字、按钮和背景已切成目标样式，仍有硬切观感。现在支持的浏览器优先使用 View Transitions：先捕获原状态，再提交新布局；外框位置、宽高与类型栏、素材区在 520ms 内衔接，面板旧内容 160ms 退出、新内容延后 80ms 淡入。不支持时保留 FLIP，收为岛 440ms、恢复 520ms。

模式偏好在转场更新回调实际提交时保存；连续切换跳过过期回调，避免稍后写回错误模式。减少动态效果时仍立即切换。

验证：`library-search-island.test.js` 7 项通过；构建及桌面前端同步成功。浏览器确认正常／岛模式双向转场实际触发且结束后清理状态；中间帧为 `.oil-ui/search-island/layout-transition-1.jpg` 和 `layout-transition-2.jpg`。本轮未实测原生桌面窗口，未测量帧率。
