# AssetVault 0.1.9

## 更新内容

- 修复重复启动与后台残留：再次启动恢复已有窗口；退出或崩溃时回收后台进程，避免下载记录被长期占用。
- 修复 Windows 进程锁误判，核对进程启动时间与程序路径，识别已退出进程和被复用的 PID。
- 关闭窗口后驻留系统托盘，在“设置 → 软件更新”中新增“退出应用”按钮。
- 补齐桌面命令权限，修复退出、更新等命令在本地工作台页面被拒绝的问题。
- 优化安装器：深色启动底色、隐藏系统标题栏、自定义退出按钮、可拖动顶部区域；显示真实安装阶段与已耗时。
- 安装器检测既有安装位置，支持沿用原路径覆盖安装。
- 将资产库状态保存到本地文件，减少安装版重启、端口变化造成的资产与收藏丢失问题。
- 新增用户数据短路径 `%APPDATA%\AssetVault` 及旧路径兼容迁移；无法迁移时保留旧目录继续使用。
- 修复重复下载判断，统一处理选项顺序及已下载记录被失败历史遮挡的情况。
- 将 AI 拆解入口整合到搜索栏，生成搜索词后回填；支持多个搜索词并行检索与分页。
- 完善中文搜索翻译与模型预览交互。

## 下载与更新

- 首次安装或手动覆盖安装：下载 `AssetVault_0.1.9_x64-setup.exe`。
- `AssetVault_0.1.9_x64-update.exe`、对应 `.sig` 和 `latest.json` 用于应用内签名更新。
- 覆盖安装保留用户数据；正在下载的任务请先完成或暂停再更新。
