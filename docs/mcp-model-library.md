## 1. 启动

推荐使用 Windows Chrome 或 Edge。当前电脑已安装 Node.js v24.15.0、npm 11.12.1 和项目依赖，无需重新安装。

双击项目根目录的 **`Start-Library.cmd`**。脚本会构建独立工作台、启动本地服务并打开浏览器：

**http://127.0.0.1:4178**

保持启动窗口开启；关闭窗口会停止服务。也可在项目目录运行：

```sh
npm install                 # 仅首次安装依赖时需要
npm run library -- --open    # 构建、启动，并在 Windows 打开浏览器
```

仅构建：`npm run build:library`。
直接启动已构建版本：`node server/library.mjs --open`。
端口占用时，先打开已有工作台；需要第二个实例可设置环境变量 `SFX_PORT`。固定使用同一个地址和端口，以免浏览器把它视为另一份本地列表。

这不是双击 HTML 即可工作的离线页面，也不需要安装新的浏览器扩展。原 Tampermonkey 脚本仍然保留，独立构建入口互不覆盖。

## 2. 已实现的工作流程

1. **输入网页**：Sketchfab 模型、搜索、作者模型页、喜欢列表、具体合集页，或普通公网网页。
2. **发现模型**：提取 Sketchfab 链接或 embed、按模型 UID 去重，读取真实名称、作者、缩略图、面数、动画数及平台下载标记。
3. **卡片库**：深色中文界面；网格/瀑布流视图、关键词搜索、开放下载/动画筛选、名称/热度/收集时间排序、收藏；左侧栏顶部的「模型模式 / 图片模式」一键切到「全部平台的模型」（A 站锁 Marmoset 可转 3D 分面，筛选合并成一棵统一分类树）或 ArtStation（瀑布流参考图）；检索历史改为点搜索框时弹出的浮层（不再常驻左侧栏）。
4. **3D 预览**：点卡片打开一个真正的 Sketchfab 交互 iframe，可旋转、缩放；关闭即释放 iframe。不把普通缩略图冒充可交互 3D，也不同时启动整页几十个查看器。
5. **下载**：点击下载，确认拥有授权，进入串行队列。支持多选、取消、错误日志和重试。任务中断后不会自动恢复下载，需要再次确认。
6. **本地保存**：默认交给浏览器保存 ZIP；设置中可选择文件夹（需要浏览器支持并由用户授权）。目录内遇到同名文件会自动编号，不覆盖已有文件。页面准确区分“已保存到所选文件夹”和“已交给浏览器下载”。

导出选项包括完整包/GLB 内容打包、下载贴图、PNG、快速 ZIP、2K/4K/原尺寸。GLB 模式仍会以 ZIP 形式附带 README 和信息文件；不是直接另存为单个 `.glb`。

首次打开且本地列表为空时，会联网载入一页平台标记为可下载的公开模型，**不是预置假模型**。这些模型的许可各不相同，仍需逐个核对原页面。

## 3. 明确边界

### 网页发现

- 当前仅适配 **Sketchfab**，其他 3D 平台需要独立适配器。
- 每页通常 24 条；支持继续分页、按 120/300/500 上限连续检索，以完整页为单位停止，不保证恰好取得该数量。
- 普通网页只读取该页返回的 HTML/文本，不执行网页 JavaScript，不递归抓取整个网站，不读取登录会话。单页最多保留 500 个模型链接。
- 原导出引擎只支持 32 位十六进制 UID。列表 API 返回旧式 ID 或不完整记录时会明确提示跳过，不能声称完整获取合集。短链、私有、删除及动态加载内容不保证可识别。
- 模型库在此浏览器 localStorage 中保存最近最多 1000 条元数据、8 条检索记录、最近 80 条任务摘要；不是云端备份。清理浏览器数据会丢失列表，但不删除已下载的文件。
- 请求遇到拒绝访问、限流等情况会直接报错，不绕过登录或权限。

### 导出和预览

- 复用现有浏览器/WASM 引擎，没有重写模型转换器；骨骼、动画、材质兼容性仍受原引擎限制。
- **独立工作台不做扩展式 viewer-blit 纹理捕获。** 出现 `MISSING_BLIT.txt` 时，任务界面会提示部分 CDN 贴图未经视图捕获校验；应检查导出外观，不能把 ZIP 成功保存视为所有贴图均正确。
- 若转换没有生成 GLB，工作台会明确失败，不把只包含中间文件的 ZIP 当作完整成功。
- 取消会停止网络请求；已经开始的同步 CPU 转换可能需要等待结束，之后丢弃结果。不是可立即终止的独立进程。
- 大模型在浏览器中转换，可能占用较多内存。保持页面打开；推荐先使用 2K 贴图。未做全平台、大规模模型兼容率或完整 4K 压力承诺。
- 默认浏览器下载可能受“允许多个文件下载”设置影响；请查看浏览器下载列表。选择文件夹的授权仅用于本次页面会话，不会秘密持久保存目录权限。
- 缩略图与 iframe 需要联网。网络/平台限制可能影响嵌入预览；模型详情提供原页面入口。

### 本机安全与网络

服务只监听 `127.0.0.1`，校验 Host/Origin，不开放任意文件读取。网页请求校验公网 IP、固定已校验的 DNS 地址，逐跳验证重定向；模型资源代理仅允许 Sketchfab HTTPS 域名。元数据、图片及单个资源均有大小限制。

**Fake-IP 代理注意：** 本机试验中，GitHub 域名曾解析到非公网地址，被安全校验正确拒绝。因此普通网页适配器已通过 HTML/嵌入/分页夹具测试，但没有把这个被阻止的 GitHub 网页冒充为成功联网验收。如遇同类提示，应在代理软件中为目标域名配置真实 DNS；不要通过关闭内网防护解决。

## 5. 实现与回滚

- `src/library/`：HTML/CSS、卡片与队列、引擎适配层。

- `scripts/build-library.mjs`：独立 esbuild 输出 `dist/library/`，复用原 WASM 内联垫片。
- `test/library.test.js`、`scripts/test-library-browser.mjs`：新回归。
- `Start-Library.cmd`：Windows 启动入口。
- `package.json`、`README.md`：新增命令和入口说明。
