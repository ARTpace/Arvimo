# Arvimo 设置整合

## 已共用的部分

- 唯一设置窗口、五类导航、直接可点的页签和插件设置注册。
- `apps/assetvault/src/library/settings-controls.css` 为主窗口与画布设置 Shadow DOM 共用的控件样式。更新它同时影响两端，不再复制颜色和控件规则。
- 画布已有 `SectionBlock` / `SettingsRow` / `Segmented` 保留，使用语义属性映射到同一套样式；独立画布运行保留自己的皮肤。
- 插件贡献可声明 `category`。已知旧贡献由宿主兼容表归类，未知扩展按原 `navGroup` 归类，不再通过名称正则猜测功能。
- 原实例、事件、存储键和密钥读取保持兼容；不重新创建一份设置数据。

## 功能边界与后续迁移

| 设置 | 当前范围 | 复用策略 |
| --- | --- | --- |
| 应用外观 | 资产库背景、面板透明度 | 统一控件样式；保留机器外观键 `av-appearance-v1` |
| 画布外观与当前画板背景 | 画布内主题工作台 | 只在画布内调节，背景颜色和上传位于“背景与壁纸”；统一设置不再注册外观、背景页 |
| 语言、快捷键 | 当前仅画布消费 | 明示范围；主应用国际化完成后再推广为全局设置 |
| Gemini 密钥 | 画布生成、Gemini SDK | 从通用移动到连接分类，保留 `ai.geminiApiKey` |
| 资产库 AI 连接 | Chat Completions、搜索与嵌入 | 与 Gemini 协议不同，不覆盖彼此的密钥或模型 |
| 画布 AI 模型 | 生成提供商、ComfyUI 等 | 保留原管理器；后续用明确的协议能力做连接复用 |
| 存储 | 下载目录、画布偏好/工程卷 | 同分类管理，保留各自用途与现有读写 |
| 更新、启动、会话 | 主桌面应用 | 嵌入画布不再显示独立应用的重启按钮 |
| 插件、MCP | 画布扩展运行时 | 贡献到统一窗口，不引入第二套插件管理器 |

## 迁移验收

下一次合并实际配置字段时，需同时验证旧值兼容、修改生效、重启保留、写入失败可见，再移除旧写入路径。当前迭代不迁移存储或合并不同协议的 AI 密钥。

常用路径：齿轮一次打开设置；分类一次切换；页签一次进入具体设置。主题工作台保留直接按钮，它包含完整预览编辑功能，不复制为另一套主题编辑器。
