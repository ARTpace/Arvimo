日期：2026-09-19

## 现在怎么用

启动方式不变：双击 **`Start-Library.cmd`**，或在项目目录运行 `npm run library -- --open`。

打开 **http://127.0.0.1:4178**。如果原页面还开着，请刷新一次；服务的 `/api/health` 应显示工作台版本 `2.0.0`。

1. 进入默认首页 **发现资产 → 搜索资产**。
2. 输入关键词，例如 `robot`、`car`、`architecture`、`sci fi helmet`，按 Enter 或点“搜索资产”。不再需要先到官网找 URL。
3. 按分类、可下载、有动画、精选筛选；选择相关度、最多点赞、最新发布或最多浏览排序。
4. 点击卡片打开 Sketchfab 交互式 3D 预览。查看许可证及原页面链接。
5. 喜欢的模型点 **加入模型库**，或点爱心收藏。需要下载时直接点击 **下载**、确认授权，无需先入库。

中文关键词会按原文提交给平台，不进行静默翻译。对于“机器人”“汽车”“科幻头盔”等内置常用词，会显示可选英文建议；只有点击建议后才改用该英文关键词。这是小型词表辅助，不是通用 AI 语义搜索，不依赖外部翻译 API。

## 四个区域的区别

| 区域 | 数据来源与保存规则 |
|---|---|
| 发现资产 | 在线搜索 Sketchfab 公开模型。结果仅在当前会话中保留，不会自动进入本地库 |
| 解析网页 | 在发现资产中切换入口；保留作者/合集/链接/embed 解析，与关键词搜索各自保存本次结果 |
| 我的模型库 | 只保存主动加入或收藏的模型，以及兼容导入的旧版列表。这里的搜索只筛选本地记录，不发起在线查询 |
| 我的收藏 / 下载任务 | 收藏是模型库的子集；下载任务自带模型快照，切换搜索或清理模型库后仍能基于任务记录重试 |

取消爱心不会删除已加入模型库的模型。可通过卡片移除按钮单独移除，或清空本地模型库；这些操作不会删除磁盘上的下载文件。

## 本轮变更

- 新增受本机请求标识保护的 `POST /api/search`；直接调用公共 `/v3/search?type=models`，固定每页 24 条。
- 18 个真实分类 slug 来自本轮 `/v3/categories` 联网核对。分类、动画、可下载、精选和排序作为接口参数发送，不是只在已加载的卡片中假装“全站筛选”。
- 默认无关键词时浏览热门；输入关键词后的默认排序为接口相关度。平台默认相关度不等同于复制官网个性化算法。
- 分页保留平台顺序、按 UID 去重。仅显示“已加载数量”，不编造平台总数；重复分页地址会停止。
- 新查询取消旧请求，并校验请求序号，旧的慢响应不能覆盖新查询。失败或取消时保留上一次成功结果，标题仍对应那次成功查询。
- 搜索/解析结果与本地模型库分离，支持单个或多选入库。收藏会明确入库；单纯导出只产生任务记录。
- 许可证和“可下载”分别显示；Creative Commons 许可可打开原条款。**可下载不等于可以商用。**
- 搜索历史支持一键恢复关键词与筛选；保留网页历史入口。详情标签可点击再次在线搜索。
- 已有导出只显示“已有导出记录”，不把浏览器下载交接误称为已验证磁盘文件存在。
- 模型库满 1000 条时拒绝继续加入并提示整理，不再静默挤掉旧记录或收藏。本次在线结果单组最多保留 1000 条，之后需缩小检索范围。

## 旧数据兼容

- 保留原键 `sfx-library-v1`，不覆盖、不删除它。
- 第一次进入新版时，把原模型、收藏、网页历史、导出设置和任务摘要兼容载入，写入新键 `sfx-library-v2`。
- 旧版列表中曾自动收集的模型也会保留；不会擅自判断哪些“不重要”然后删掉。
- 旧的进行中任务会显示“上次会话已中断”，不会自动下载或把它们标为成功。
- 后续优先使用 v2，即使 v2 模型库已被用户清空，也不会再次从旧键恢复旧模型。
- 结果列表不写入持久化存储；历史最多 12 条、任务摘要最多 80 条。文件夹授权仍只用于当前页面会话。
- 格式损坏的存储会尝试保留原始备份并提示。浏览器禁止存储或空间不足时会报告保存失败，不声称记录已保存。

## 平台与权限边界

本轮仅搜索 **Sketchfab 公共资产**，不包含 Fab 商城，不保证公开接口与官网的结果数量、排序完全相同。私有、删除、登录限制及旧式 UID 仍受现有支持范围限制。

网页解析继续只处理页面返回的链接/嵌入，不执行外部站点 JavaScript，不递归扫描整个网站。原有内网/保留 IP、DNS 固定、重定向检查、Sketchfab 资源代理白名单、Host/Origin 和 CSP 防护保留。

下载仍复用原浏览器/WASM 转换器。仅用于自有或已获授权模型；转换失败、取消和贴图警告继续如实显示。`MISSING_BLIT.txt` 代表需检查部分 CDN 贴图外观，不能因 ZIP 保存成功就保证所有材质视觉完全一致。
