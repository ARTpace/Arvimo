# 画布与资产库画板

- 一张画布对应一个普通画板，使用相同 ID；新建、改名、删除及资产成员双向同步。智能画板继续按规则计算，不转成可编辑画布。
- 切换、新建复用画布原有的画板面板；面板内可直接打开对应资产库画板，资产库画板卡片提供直接打开画布按钮，不另叠工具条。
- 文件通过现有 `/api/library/drop-import` 流式入库及内容去重，画布保存稳定资产引用。移出画布或画板只解除成员关系，不删除库内资产或源文件。布局、形状、便签和相机仍属于画布文档。
- SQLite `canvas_project` 保存工程及引用映射，`collections` / `collection_assets` 保存画板与成员；同一资产可出现在多张画布。
- `/api/library/artflow-board` 的 GET 返回同步后的工程；PUT 接受 `{document, base}`，按客户端基线合并修改，避免延迟保存覆盖库侧增删。画布变化合并保存，库侧变化在返回画布或最多约 3 秒后更新。
- 旧 `artflow-board.json` 首次读取时迁移；原文件保留作恢复副本，不再双写。旧数组工程由前端原有解析器转换后同步。
- 旧工程失效的 `blob:` 音视频引用保留节点，不阻塞其他画板迁移或创建，也不伪造库内文件。前端遇到无法读取的旧临时素材会提示重新导入。
- 本机同源页面才能同步，局域网访客和跨源写入拒绝；开发版与正式版各自沿用独立数据目录。

验证：`node --test test/library-canvas-boards.test.js`（在 `apps/assetvault` 运行）。
