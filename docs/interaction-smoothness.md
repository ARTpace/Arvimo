# 交互流畅度优化（2026-10-31）

方向：立即响应、过渡短、位置稳定；保留深色工作台、绿色强调和小猫助手。

主要任务仍是浏览、检索、筛选、预览和下载资产。沿用现有页面结构与原生滚动，不引入滚轮接管、动效依赖或整页转场。只去掉让操作等待的装饰：平台菜单逐项延迟出场、输入提示打字机和输入框持续阴影呼吸；不删业务文案、分类或功能入口。

- 下拉与历史：整体 140ms 展开；所有选项立即出现；定位合并到每帧一次，锚点消失就收起，菜单边界不继续滚动背景。键盘移动只更新高亮，不重建记录。
- 筛选与设置折叠：200ms 展开、150ms 收起，可从当前高度反向；初始化和减少动态效果时直接到位。筛选折叠内容不进入键盘焦点。
- 抽屉与侧栏：220ms，退出期间保留内容，避免面板先变空；收起抽屉后归还焦点。
- 页面与设置分类：保留各自滚动位置，快速切换取消旧的滚动恢复；用户滚轮和触摸优先。设置分类切换用 140ms 轻淡入。
- 指针反馈：眼睛位置统一先读后写，搜索按钮跟随每帧至多一次；后台暂停搜索区 CSS 动画。

验收：正常与快速反向操作、键盘选择/Esc、菜单内滚动、侧栏与抽屉、设置折叠/分类、页面返回位置；检查桌面及窄屏。逻辑测试用 `test/library-interaction-motion.test.js`，视觉证据放在 `artifacts/interaction-smoothness/`。不以逻辑测试推断帧率。
